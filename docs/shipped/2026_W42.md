## 2026-10-17 · Completion certificates

**Intent:** provide a downloadable certificate, verifiable through a public URL, after course
completion, with a QR code pointing to that same public page.

issuance inside `completeLesson`. Name, course, and date were retained as issuance snapshots.

rendered with Poppler and reviewed with maximum-length names/titles. Vision decoded the PDF QR
to exactly the expected URL.

**Scope:** local implementation and verification; no external deployment.

## 2026-10-17 · Required exam for new certificates

**Changes:** administrative course exam configuration with 15 four-option questions, one correct
answer each, and an initial passing threshold of 12 (80%). Completing lessons only unlocked the
exam. The server graded submissions and saved the passing attempt with the certificate. Versions
prevented grading against an answer key edited during an attempt; transactions prevented duplicates.
Existing certificates retained validity. The additive migration was applied locally.

**Verification:** service/platform builds, lint, test typecheck, boundaries, and documentation
citations passed. Results: 732 service unit tests, 81 PostgreSQL integration tests, and 368 frontend
tests. Integration used a disposable migrated/seeded database, log email, and fake video. Isolated
Chrome verified 15-question configuration through the UI, 11 correct answers without a certificate,
a retry with 12, and public certificate/PDF access. Desktop and mobile had no horizontal overflow.
The test environment was removed afterward.
